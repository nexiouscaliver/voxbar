## Fixed: Each Phone Keeps Its Own Recent List

The identity tag the Mac reads from a phone is the first characters of
the phone's device id, and the backup id a browser mints when it lacks
the crypto id API used to begin with a timestamp. Two such phones first
paired in the same hour could mint tags that matched, and the Mac folded
them into one Recent list. The random half of the id now comes first, so
the tag differs per phone. The Mac also keeps a durable record of the
phones you have paired, seeded at startup and saved across restarts, and
two phones pairing in the same instant are resolved atomically, so
concurrent twins can never be assigned each other's lane.

## Fixed: A Dying Client Cannot Stall The Phone Server

Setting up a phone connection used to run its settings reads and writes
and tray updates on the server's own async tasks, so a storm of
reconnecting phones could pin every runtime worker and stall new
connections at the accept loop. That bookkeeping now runs on separate
workers, and a worker that fails says so in the app log instead of
vanishing. The server's internal locks no longer die with a panicked
client: a failure while opening one phone's audio used to poison a lock
so that every later phone touching it failed too; the locks now recover
in place. A phone that dies mid-handshake has its lane fully torn down
instead of lingering as a phantom tray entry, and phones that connect
and disconnect repeatedly stop growing the app's internal session maps.

## Fixed: Honest AI Polish Is No Longer Rejected

The guard that watches an AI post-process for numbers rewritten into a
digit script nobody sanctioned over-tripped on genuinely mixed text. A
text whose digits split evenly between two scripts was always judged
Latin, and a number the transcript itself contained in a minority
script counted as a rewrite. A tie now reads as the mixed text it is,
and a carried-over number is judged by whether the transcript actually
held it, so a cleanup that keeps your numbers exactly survives while a
true rewrite still fails.

## Fixed: Escape Cannot Be Lost To A Timing Race

In Secure Input fields, when one dictation released its claim on the
Escape key in the same moment another took its own, the last update
could win and leave a live session without Escape handling, or leave
Escape armed after every session had ended. The claim bookkeeping now
updates under the same lock as the claim set itself, so its final state
always matches the sessions that are actually live.

## Fixed: Counters That Count In Every Language

The live log read "1 lines" at one line in English. The secure input
banner picked its plural form by hand and got the grammar wrong in
Russian, Ukrainian, Polish, Czech, Hebrew, and Arabic. Plural forms now
come from each language's real rules in all 26 supported languages.
Russian and Ukrainian use their singular form at 21, 31, and 101, not
only at 1, and several Prompt Studio counters had the numeral 1 baked
into that form, so 21 results read as "1 result"; the real count is
rendered now.

## Fixed: A Round of Smaller Repairs

- The green Granted labels in the light theme now clear the 4.5:1
  contrast bar they were documented to meet, along with the three
  sibling green labels that shared their shade.
- The App Data and Log Directory buttons, and the button that opens the
  microphone privacy pane, now report a failure with a notice instead of
  silently doing nothing or arming a wait that can never finish.
- On Linux direct typing, a transcript with Windows or old-Mac line
  endings no longer types a stray carriage return at the end of every
  line.
- Flipping the laptop lid when no closed-lid microphone is configured no
  longer stops and reopens the microphone: the choice could not have
  changed, and the reopen briefly blocked every other recording start
  and stop.

## Behind The Scenes

The zero-audio recovery advice that names your mode, introduced last
release, is locked by tests across all 26 languages, so it cannot
quietly regress to the generic hint. The web layer's permission list
drops a file-open entry no code used; opening the app data and log
folders goes through the app's own native path and keeps working. The
engineering defect ledger was reconciled against this release line by
line, and the test suite now checks the code citations in its entries,
so an entry can no longer point at code that has moved.
