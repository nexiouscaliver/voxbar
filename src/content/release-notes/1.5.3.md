## Commands That Respect The Language

Spoken command words in Chinese no longer trigger when the same characters
appear inside ordinary words: the alias must end at a word boundary, so
dictating about 行业 (industry) no longer inserts a line break through the
hidden 换行 (new line). The command-key badge in the overlay also stops
lighting up on models that cannot interpret commands in the first place.

## Housekeeping

Deleting a model while it downloads no longer reports the download as
completed for a model that no longer exists. A fallback hotkey that failed to
clean itself up now retries on the next change instead of firing twice. The
release scripts are now syntax-checked on every push.
