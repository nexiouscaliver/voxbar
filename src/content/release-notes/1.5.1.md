## The Gate Stops Guessing

The memory gate measured one model and applied that reading to every other
model, so switching from a large model to a small one could refuse the small
model or silently swap it away. Measurements are now kept per model, exactly
like the local LLM gate, and the numbers in a refusal message are always the
model you actually selected. The auto-fallback picker now checks memory with
the same arithmetic the load itself uses, so a fallback it chooses can no
longer be refused on arrival.

## Your Dictation Survives The Menu Bar

Clicking Unload model in the tray during a live dictation used to kill the
dictation silently. It now declines while a session is live, and even if an
unload slips through, transcription reloads the model on demand instead of
failing. Deleting the model a live session is using is refused with a clear
message.

## Command Mode Between Snapshots

A quick press and release of the command key could land entirely between
streaming updates, and the command you spoke pasted as plain text. Those
missed holds are now captured and parsed, with any dictation spoken just
before the press preserved. Ending a dictation while the command key's
window is still open keeps the words you spoke after release instead of
discarding them.

## Paste Failures Tell You

When the paste keystroke itself failed, VoxBar used to report success; the
failure now surfaces like any other paste failure, with a notification when
the window is hidden.

## Networking

Pairing a phone while a corporate VPN is up no longer advertises the VPN
address; physical Wi-Fi ranges are preferred for the QR code and the
connection.
