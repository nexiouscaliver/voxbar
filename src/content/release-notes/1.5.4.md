## Verified Releases And Downloads

The macOS release pipeline now proves the app really links Apple
Intelligence before it ships, so a broken build fails the release instead
of reaching users. Models added from HuggingFace get their sha256 checked
after download, catching a truncated or tampered file before it loads.

## Quieter Phones, Honest Settings

Undo and delete-word feedback no longer buzzes the paired phone: every
notice code only the Mac keyboard can trigger now stays off the
forwarder. Settings changes made before the saved settings load are kept
and applied once instead of lost or written twice, the tray menu stays
accurate after prompt and provider changes, and CI and tests hardened.
