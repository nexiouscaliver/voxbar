## New Lines Finally Survive

Saying "new line" or "new paragraph" while dictating now works end to end. The line break shows up live in the overlay while you speak, and it lands in the pasted text exactly where you said it. A trailing "new line" keeps its break too, so you can end a message ready for the next one.

## Command Mode Got Sharper

Two long-standing command mode annoyances are fixed:

- Command words split across streaming snapshots no longer vanish. If the engine heard "com" and then finished it as "comma", the comma now lands. Before, the half-heard word was thrown away silently.
- Repeating the same symbol command no longer doubles it up. Saying "comma" twice in a row while holding the command key gives you one comma, not two.

Deletions are now visible too. When the delete-word hotkey or a command mode "delete word" / "delete line" removes text, the overlay briefly shows what was removed, struck through, so a slip of the key is never a mystery.

## Auto-Interpret Commands Toggle

New setting, on by default: **Auto-Interpret Commands** (Settings, under Transcription). When it is off, command words like "comma" or "scratch that" are typed as plain words in normal dictation. Hold the command mode modifier to enact commands as usual. This is the escape hatch for when you want to dictate the word "comma" without getting a comma.

## The Command Matrix

Every spoken command phrase now lives in one editable table: Settings, under Transcription, **Command Matrix**. Add or remove phrases per command, and the same phrases work everywhere: command mode, spoken punctuation, and spoken deletion. "scratch that" now also works while holding the command key, and "delete word" works in normal speech.

The symbol set grew with it. You can now speak:

- at sign, hash, dollar sign, percent, star, asterisk, ampersand, caret
- open/close paren, parenthesis, bracket, square bracket, brace, curly brace
- slash, forward slash, backslash, pipe, vertical bar

plus the punctuation that was already there (period, comma, question mark, exclamation mark, colon, semicolon, dash, new line, new paragraph). A "reset to defaults" button puts the built-in phrases back.

## Hindi and Hinglish, No Translation Ever

Hindi speech already works with any Hindi-capable model. New in this version:

- **Hinglish (Roman script)** in the language picker. Pick it once and Hindi speech comes out in Roman letters, live in the overlay and in the paste, so code-mixed speech stays readable in the script you type in.
- The language fallback got smarter: if your language is set to something other than English, VoxBar will refuse a model swap that would silently change your language, instead of quietly transcribing your Hindi as English.

The no-translation rule is absolute: nothing in this version ever translates your speech. English in, English out; Hindi in, Devanagari (or Roman with Hinglish selected) out.
