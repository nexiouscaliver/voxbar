## In-App Updates

VoxBar can now update itself. Use "Check for Updates" in the tray menu or the settings footer: the app downloads the new version, installs it, and relaunches, all in place. No more downloading a zip and dragging it over the old app, and no more Gatekeeper dance after the first install. Updates come from this project's GitHub releases and are verified against a signing key embedded in the app before they install.

Update checks can be turned off in Settings, under General. The first install still needs the one-time "Open Anyway" step described in the README, because the first download comes through your browser.

## The Memory Guard Stopped Getting In The Way

The memory-pressure guard used to demand a hidden one and a half GB of spare RAM above the model's own size before loading anything, which blocked perfectly reasonable first loads on normal machines. It now asks only that the model fit the memory you actually have. If you want the old caution back, Settings, under Advanced, has a new "Memory safety margin" control: pick Off (the default) or a fixed margin, and the guard refuses loads that would leave less than that free. The existing "Memory Pressure Guard" toggle still turns the whole check on or off.

## A Refused Load Is No Longer A Dead End

When a model genuinely does not fit, first-run setup used to fail with a wall of text and no way forward. The refusal is now a card with the real numbers (what the model needs, what is free) and four ways out: retry, pick a different model, load it anyway with the guard off, or continue without loading now and let the first dictation load the model on demand. The message also stopped rounding small models to a nonsense "0.0 GB".

## First-Run Fixes

- If microphone permission is denied, the setup screen now waits with a timeout and then offers to open the right System Settings pane, with a "Check Again" button instead of an endless spinner.
- If the permission poller dies, the Grant buttons come back instead of leaving a stuck screen.
- The success screen and model picker now show your actual dictation shortcut, so you know which key to hold.
- Model download failures name the model in the error message.
- Pressing the dictation hotkey before any model is selected now explains itself instead of failing silently.
